## 先理解目录树

Linux 用一棵以 `/` 为起点的目录树组织文件。`/etc` 保存系统配置，`/home` 通常存放普通用户的主目录，`/tmp` 用于临时文件。目录名描述的是用途，而不是独立磁盘的盘符。

绝对路径从 `/` 开始，不依赖当前目录；相对路径从当前目录开始解释。`..` 表示上一级目录，`.` 表示当前目录，`~` 通常会由 Shell 展开为当前用户的主目录。遇到路径问题时，应先确认当前用户和当前位置，再执行修改操作。

## 把基本命令连成一个过程

下面是一组在个人练习目录中使用的示例。每条命令完成一个动作，可以逐条观察结果。

```bash
pwd
mkdir -p ~/linux-notes/practice
cd ~/linux-notes/practice
printf 'Linux file management\n' > notes.txt
ls -l
cp notes.txt notes-copy.txt
cat notes-copy.txt
```

`mkdir -p` 可以创建缺失的父目录；`cp` 复制后原文件仍然存在。`ls -l` 提供权限、属主、大小和修改时间，适合检查文件是否按预期生成。若要查看隐藏文件，可以使用 `ls -la`，因为名称以点开头的文件默认不在普通列表中出现。

## 重定向和文件名

`>` 会截断目标文件，`>>` 则在末尾追加。修改已有笔记前应确认是否需要保留原内容，不能把覆盖与追加当成同一个动作。文件名包含空格时应加引号，例如 `cp "my notes.txt" "my notes.backup.txt"`。

通配符由 Shell 展开。例如 `*.txt` 可能匹配多个文件，操作前可以先用 `printf '%s\n' *.txt` 检查范围。涉及删除时尤其需要确认路径、对象和备份，不能把系统目录作为命令练习的目标。

## 我的记忆方法

我把文件管理分成“定位、查看、修改、核对”四步：先用 `pwd` 确认位置，再用 `ls` 看清对象，随后执行单一操作，最后读取内容或比较文件。这样比只记住一串命令更容易发现路径和覆盖错误。
