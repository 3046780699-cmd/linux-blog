## 权限属于谁

Linux 文件权限通常分为属主、属组、其他用户三组。`ls -l` 显示的权限字符串中，首位表示文件类型，后面九位按三组排列。例如 `-rw-r-----` 表示普通文件，属主可读写、属组可读、其他用户无权限。

查看权限时还要同时查看属主与属组。不能只看到某一位有 `r` 就认为所有用户都可以读取。可以使用 `id` 查看当前身份和附属组，再结合 `ls -l` 判断访问时匹配哪一组权限。

## 数字权限的含义

每组权限中的读、写、执行分别对应 4、2、1。把需要的值相加即可得到一个数字。比如 `640` 表示属主可读写、属组可读、其他用户没有权限；`750` 常用于限制目录访问或脚本执行。

```bash
id
ls -l notes.txt
chmod 640 notes.txt
ls -l notes.txt
```

这组示例只调整当前练习文件。`chmod` 改变权限，`chown` 改变所有者，二者不是相同操作。修改属主通常需要更高权限，应先核对对象，避免递归改变无关文件。

## 文件和目录的 rwx 不一样

对普通文件，`r` 表示读取内容，`w` 表示修改内容，`x` 表示允许作为程序尝试执行。对目录，`r` 影响列出名称，`w` 影响创建或删除目录项，`x` 影响进入目录与按名称访问其中的对象。

因此，某个文件本身可读，并不保证用户能从上层路径访问它；父目录缺少执行权限同样可能导致拒绝访问。排查时可以逐级检查目录，而不是直接对整个目录树设置 `777`。

## 权限配置的边界

`sudo` 适合在需要管理权限时执行特定命令，不应因为遇到一次拒绝访问就让所有文件都可写。更合理的思路是核对用户、属组、路径和实际需求，再赋予完成任务所需的最少权限。
